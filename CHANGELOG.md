# Changelog

## [1.0.0] - 2026-05-03

### Agregado

- ✅ **Sitio web completo** con 6 páginas:
  - Home (/) - Landing con hero, servicios, casos de éxito, FAQ
  - Servicios (/servicios) - Catálogo completo de 10 servicios
  - Cómo Funciona (/como-funciona) - 5 pasos del proceso
  - Casos de Éxito (/casos-exito) - 3 testimonios + estadísticas
  - Legal (/legal) - Términos, privacidad, garantías
  - Contacto (/contacto) - Formulario + datos de contacto

- ✅ **Optimización SEO**:
  - Metadata dinámica para cada página
  - Open Graph tags para redes sociales
  - sitemap.xml con todas las páginas
  - robots.txt configurado

- ✅ **Accesibilidad (WCAG)**:
  - Skip-link para navegación por teclado
  - aria-labels en todos los botones
  - Labels asociados correctamente en formularios
  - Focus states visibles

- ✅ **Componentes reutilizables**:
  - Header con navegación
  - Footer con enlaces
  - Botones de WhatsApp estilizados

- ✅ **Configuración de desarrollo**:
  - ESLint configurado
  - TypeScript
  - Tailwind CSS v4
  - PostCSS

## Formato de versiones

Dado que este es un proyecto privado de marketing, las versiones son:

- **Mayor (1.0.0)**: Nuevas páginas o rediseños completos
- **Menor (1.1.0)**: Nuevas funcionalidades o mejoras
- **Patch (1.0.1)**: Arreglos de bugs o mejoras menores
