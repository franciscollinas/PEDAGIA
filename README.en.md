## 📖 About

### What is Pedagia?

**Pedagia** is an AI-powered educational services business, specialized in helping Colombian teachers automate pedagogical content creation.

### The Problem It Solves

Colombian teachers face daily challenges:

```
❌ CURRENT REALITY:
├── Work 2-3 shifts (school + private + online)
├── Earn $2.5M - $4.5M/month (insufficient)
├── Spend 15-20 hours WEEKLY creating content (unpaid)
└── Pay $30k-$150k to others for tasks (no quality guarantee)

✅ PEDAGIA SOLUTION:
├── AI specialized in Colombian pedagogy
├── Documents aligned with DBA and MEN regulations
├── 50% cheaper than informal services
└── Recover 15-20 hours/month
```

## ✨ Features

- ✅ **6 complete pages**: Home, Services, How It Works, Success Stories, Legal, Contact
- ✅ **Responsive design** optimized for mobile and desktop
- ✅ **WhatsApp buttons** on all pages for direct conversion
- ✅ **Service catalog** with clear prices and delivery times
- ✅ **SEO Optimized**: Dynamic metadata, Open Graph, sitemap.xml, robots.txt
- ✅ **Accessibility (WCAG)**: Skip-link, aria-labels, proper form labels, visible focus states

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/franciscollinas/PEDAGIA.git

# Enter directory
cd PEDAGIA/pedagia-web

# Install dependencies
npm install

# Start development server
npm run dev
```

---

## 📜 Available Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |
